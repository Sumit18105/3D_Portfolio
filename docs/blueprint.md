# **App Name**: Pathak Labs

## Core Features:

- 3D Scene Engine: Core engine to render and animate the 3D environment, handle camera movements, and manage object interactions, following the camera movement requested by the user.
- Holographic UI: Implement glassmorphism and holographic effects on UI elements like cards, panels, and buttons, using neon blue, cyan, and purple glows, as requested.
- Interactive Resume Timeline: Generate an animated, glowing vertical timeline for Sumit's resume, highlighting key experiences and achievements. Include professional history items such as AI & ML degree, Operations Manager at Makes360, Frontend Internship at IBM SkillsBuild, and Patents in VR Health Monitoring and USB Security, with associated lighting and animations on visible items.
- Dynamic Project Display: Fetch and display Sumit's projects as floating 3D cards with interactive hover effects. Dynamically loads the projects requested, such as the Mental Health Support System (MERN), Job Portal (MERN), Fire Detection (Computer Vision), OCR & Translation App, Portfolio Website, and Sudoku Wizard. The detailed modal window displays relevant project data, when opened.
- AI Assistant Integration: Develop an optional holographic AI assistant within the 3D environment, providing contextual information and guidance through voice interaction. Generative AI is used as a tool to decide when, and whether or not, the assistant should incorporate its suggestions.
- Contact Form Handler: Implement a floating glass contact form in the 3D space, allowing users to send messages directly to Sumit. Provide links to the profiles requested, such as email, LinkedIn, and GitHub.

## Style Guidelines:

- Primary color: Electric indigo (#6F00FF) to establish the site's high-tech and modern aesthetic.
- Background color: Dark charcoal gray (#222222), desaturated, lending depth to the immersive 3D environment.
- Accent color: Cyan (#00FFFF), highlights key interactive elements.
- Body and headline font: 'Space Grotesk', a sans-serif for a modern tech-oriented aesthetic, used for both headings and body text.
- Use custom neon icons for skills, projects, and contact information.
- Employ a floating layout with holographic and glassmorphic UI elements.
- Implement smooth camera animations on scroll, with parallax depth, and pulsing neon lights.
